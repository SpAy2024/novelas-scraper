# 📺 Novelas Scraper

Scraper de novelas del sitio web OjearNovelas.com con interfaz web para buscar, scrapear y reproducir novelas.

## ✨ Características

- 🔍 Buscar novelas por título
- 📥 Scrapear novelas completas
- 📚 Biblioteca de novelas scrapeadas
- 🎬 Reproductor de video integrado
- 📱 Diseño responsive

## 🚀 Instalación

```bash
# Clonar repositorio
git clone https://github.com/tuusuario/novelas-scraper.git
cd novelas-scraper

# Instalar dependencias
npm install

# Crear carpeta para datos
mkdir data
